# 中学3年 理科・物理クイズ（配布版 V3）

インストール不要、アカウント登録不要の学習クイズです。水圧・力の合成/分解・運動と力・水平面上の運動・斜面上の運動・作用反作用・仕事・運動エネルギー・位置エネルギー・力学的エネルギーの10分野を練習できます。

## 生徒向け：いちばん簡単な始め方

1. 配布されたZIPファイルを **展開** してください（ZIPの中ではなく、展開したフォルダーで操作します）。
2. `standalone.html` をダブルクリックして、Chrome / Edge / Firefox などのブラウザで開きます。**このファイル1つに、図・問題・プログラムが入っています。**
3. 分野・難易度・問題数を選んで「クイズを始める」を押します。
4. 答えを選ぶ（または数字を入力する）→ **「回答を決定する」** → 解説を見る →「次の問題へ」。
5. 結果を確認します。間違えた問題の復習や、結果の印刷・PDF保存もできます。

> `standalone.html` が開けない学校の管理端末では、先生が案内した学校サイト等からアクセスしてください。端末の利用ルールに従ってください。

## 出題設定

- 出題範囲：10分野から1～10分野を自由選択。全選択・全解除が可能。
- 問題数：1～200問。
- 難易度：**基本**（基本のみ）、**標準**（基本＋標準）、**発展**（標準＋発展）、**全難易度**（基本～発展）。
- **中学範囲を超える数式問題も含める**：初期設定はオフ。オンにすると、水圧の密度計算 `p=ρgh`、運動エネルギーの式 `E=½mv²`、直交する力の三平方計算なども出題。通常の学校範囲を復習する場合はオフが適切です。

## 回答と成績

- 回答形式：4択、複数選択、数値入力の3種類。
- 選択肢は **タップしただけでは確定しません**。選び直してから判定可能。
- 数字入力：単位を入れずに答えの数値だけ入力してください。全角数字にも対応。
- 答えが分からない場合は「ヒントを見る」。回答後は正解・理由・計算方法を確認。
- 学習履歴：分野別の正答率・最近30回の結果、復習候補150問まで。
- 途中の問題：保存可能なブラウザではホーム画面から「続きから再開」。
- 音：右上の音符からオン／オフ（初期設定オフ）。

## PNGの仕組み

模式図は19枚のPNGを使っています。PNGは絵柄だけを描き、**数値は焼き込まれていません**。問題作成時に条件・数値・単位を動的に生成して、図の上または下の欄に表示します。モバイルは読みやすさ優先で図の下にまとめて表示します。図の縮尺や矢印の長さは実際の値と比例しません。

## 保存とプライバシー

- 個人名・メールアドレスの入力欄はありません。外部への通信・外部APIの利用はありません。
- 学習履歴・復習候補・途中の問題は **ブラウザ内のlocalStorage** に保存します。ブラウザやファイルの場所が違うと、履歴が共有されない場合があります。
- **学校の共有端末では、学習終了後に「学習履歴」→「学習記録を削除」** を使ってください。ブラウザの保存設定により履歴が残らない場合もあります。
- 「履歴をCSVで保存」で出力したファイルや「結果を印刷・PDF保存」で作成したファイルは、保存・提出場所に注意してください。
- クイズの結果は練習用です。出題が毎回変わるため、学校の成績評価にそのまま用いる公平な試験設計ではありません。

## その他

- オフライン使用可（必要な画像やJSを同梱）。外部フォントやCDNを使いません。
- 機能の制限はブラウザや学校端末のセキュリティ設定に依存します。
- HTML・CSS・JavaScript・PNG を修正したい場合は `index.html` および `js/`, `styles.css`, `assets/` を使ってください。公開時の入口は `index.html` です。
- グラフィック・問題文は本教材用のオリジナル素材として制作されています。

先生が配布する場合は `TEACHER_GUIDE.md`、品質監査内容は `AUDIT_REPORT.md` と `TEST_REPORT.md` を参照してください。
